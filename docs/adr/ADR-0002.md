# ADR-0002: Use PostgreSQL With Schema-Validated JSON Resume Documents

Date: 2026-07-03

## Status

Accepted

## Context

Resume documents are nested and change shape as sections and templates evolve. Billing, users, exports, and audit events are relational.

## Decision

Use PostgreSQL as the primary database. Store resume document bodies in JSONB during MVP, validated with Zod schemas, while keeping ownership, metadata, versions, subscriptions, and exports relational.

## Consequences

- Iterating on resume schema is faster.
- Relational integrity remains available for business-critical entities.
- Analytics queries against resume content may require promoted columns later.
- Version migrations must be deliberate as document schemas evolve.
