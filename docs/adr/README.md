# Architecture Decision Records

This directory records consequential architecture decisions for CareerLaunch Studio.

## Index

- `ADR-0001.md` - Use a TypeScript monorepo modular monolith.
- `ADR-0002.md` - Use PostgreSQL with schema-validated JSON resume documents.
- `ADR-0003.md` - Start with synchronous export and defer queue infrastructure.

## Rules

- Write ADRs only for decisions that affect architecture, cost, operations, data, security, or delivery speed.
- Keep ADRs short and update status if a decision is superseded.
- Do not use ADRs as general planning notes.
