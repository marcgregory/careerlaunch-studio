# ADR-0003: Start With Synchronous Export and Defer Queue Infrastructure

Date: 2026-07-03

## Status

Accepted

## Context

PDF export is core to user value, but adding queue infrastructure before proving export load would slow the MVP.

## Decision

Implement Sprint 1 PDF export synchronously if it reliably finishes within the release budget. Add background jobs only when export, import, or AI tasks exceed request limits or create reliability issues.

## Consequences

- MVP has fewer moving parts.
- Export performance must be measured early.
- The architecture keeps an `ExportJob` concept so async processing can be introduced without changing user-facing flows.
