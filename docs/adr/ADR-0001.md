# ADR-0001: Use a TypeScript Monorepo Modular Monolith

Date: 2026-07-03

## Status

Accepted

## Context

CareerLaunch Studio needs a rich web builder, shared domain schemas, resume rendering, billing, auth, and future AI assistance. The first team is assumed to be small and needs fast delivery.

## Decision

Use a TypeScript monorepo with a Next.js app and shared packages. Keep the runtime architecture as a modular monolith for MVP.

## Consequences

- Shared types and validation stay consistent across UI, server actions, and tests.
- Deployment remains simple.
- Feature boundaries must be enforced by convention and package exports.
- Services can be extracted later if scale or ownership requires it.
